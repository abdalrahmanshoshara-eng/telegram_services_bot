# بوت خدمات تيليغرام

بوت خدمات احترافي يدعم الخدمات المرتبطة بمنصات خارجية ومعالجة الملفات محليًا. يختار المستخدم الخدمة بالزر أو بإرسال رقمها، وتُحذف ملفات العمل المؤقتة بعد إرسال النتيجة.

تعرض الواجهة أصناف الخدمات أولًا، ثم تعرض خدمات الصنف المختار فقط. ويمكن للمستخدم الضغط على زر الخدمة أو إرسال رقمها داخل الصنف الحالي.

## الخدمات

1. منصة إعداد العقود.
2. تنسيق جداول Word ومنع انقسام الصفوف.
3. إزالة خلفية الصور باستخدام النموذج الخفيف `u2netp`.
4. دمج عدة ملفات PDF حسب ترتيب الإرسال.
5. استخراج صفحات ونطاقات من PDF، مثل `1-3,5,8`، مع دعم الأرقام العربية.
6. إدارة صفحات PDF بالتدوير والحذف وإعادة الترتيب.
7. حماية PDF بتشفير AES-256 وفك الحماية بكلمة المرور الصحيحة.
8. تحويل عدة صور إلى PDF.
9. ضغط الصور وتحويلها إلى JPG أو PNG أو WEBP وتصغيرها.
10. إضافة علامة مائية نصية عربية أو صورة شعار إلى PDF.
11. إنشاء QR Code من رابط أو نص.
12. استخراج النص العربي والإنجليزي من الصور إلى TXT.
13. تحويل جهات الاتصال من ملف أو عدة ملفات Excel أو CSV أو TXT أو VCF أو Word أو PDF إلى VCF وملف استيراد لـ Google Contacts، مع تنظيف الأرقام ودمج المكررات وحفظ الجهة بكل أرقامها، وتقارير المراجعة.
14. تنظيف XLSX من الصفوف الفارغة والمكررة والمسافات الزائدة.
15. تقسيم XLSX حسب قيم عمود إلى حزمة ملفات ZIP.
16. دمج عدة ملفات XLSX كصفوف متطابقة أو كأوراق مستقلة.
17. تحويل نسخة ColorNote واحدة أو عدة نسخ إلى أرشيف HTML مستقل قابل للبحث والتصفح.
18. إنشاء عرض تقديمي PowerPoint من ملف PDF أو DOCX بالهوية البصرية السورية عبر Gemini.
19. تدقيق نص عربي غير منسق وتحويله إلى الفصحى مع تصحيح الإملاء والترقيم والمسافات عبر Gemini.
20. جمع محتوى عدة ملفات DOCX في ملف Excel واحد: صف لكل ملف، العمود الأول اسم الملف والثاني نصه الكامل بما فيه الجداول.
21. ضغط ملفات PDF بثلاثة مستويات: بدون فقدان جودة، ومتوسط، وقوي.
22. تحويل ملفات Word وExcel وPowerPoint إلى PDF عبر LibreOffice، مع ضبط خاص بالملفات العربية.

الأوامر: `/start` و`/services` و`/done` و`/cancel`.

## التشغيل باستخدام Docker - الطريقة الموصى بها

المتطلبات:

- Docker Engine مع Docker Compose.
- خادوم موصى به: 2 vCPU و4GB RAM و20GB مساحة.
- اتصال بالإنترنت في أول تشغيل لتنزيل نموذج `u2netp` الصغير.

انسخ ملف الإعداد:

```bash
cp .env.example .env
nano .env
```

ضع التوكن الجديد في:

```dotenv
BOT_TOKEN=ضع_التوكن_الجديد_هنا
```

لا ترفع ملف `.env` إلى GitHub. شغّل البوت:

```bash
docker compose up -d --build
docker compose ps
docker compose logs -f
```

في أول تشغيل يجهّز الـentrypoint نموذج إزالة الخلفية داخل volume دائم، ولن يعيد تنزيله بعد إعادة إنشاء الحاوية.

### واجهة الويب «منصة الخدمات الرقمية»

يشغّل الأمر نفسه حاوية ثانية `telegram-services-ui` من نفس الصورة، فيها صفحة ويب لتجربة جميع الخدمات المباشرة دون تيليغرام. افتحها من الخادوم نفسه على:

```
http://127.0.0.1:8765
```

الصفحة بلا تسجيل دخول، لذلك تُنشر افتراضيًا على `127.0.0.1` فقط. للوصول إليها من جهازك عبر SSH:

```bash
ssh -L 8765:127.0.0.1:8765 user@server
```

ثم افتح `http://127.0.0.1:8765` على جهازك. لا تضبط `UI_BIND=0.0.0.0` إلا خلف VPN أو بروكسي يطلب تسجيل الدخول. لتشغيل البوت وحده دون الواجهة:

```bash
docker compose up -d telegram-services-bot
```

للتحديث من GitHub:

```bash
git pull --ff-only
docker compose up -d --build
docker image prune -f
```

لإيقاف البوت دون حذف النموذج:

```bash
docker compose down
```

لا تستخدم `docker compose down -v` إلا إذا أردت حذف volume النموذج وإعادة تنزيله.

## التشغيل دون Docker

على Ubuntu/Debian:

```bash
sudo apt update
sudo apt install -y \
  python3 python3-venv fonts-dejavu-core libgl1 libglib2.0-0 \
  libmagic1 tesseract-ocr tesseract-ocr-ara tesseract-ocr-eng \
  libreoffice-writer-nogui libreoffice-calc-nogui libreoffice-impress-nogui fonts-noto-core fonts-noto-ui-core fonts-hosny-amiri \
  fonts-kacst fonts-kacst-one fonts-liberation2 fonts-crosextra-carlito fonts-crosextra-caladea
sudo cp services/office_to_pdf/fonts.conf /etc/fonts/local.conf
sudo cp -r assets/syid/fonts /usr/local/share/fonts/syid && sudo fc-cache -f

python3 -m venv .venv
.venv/bin/pip install --upgrade pip
.venv/bin/pip install -r requirements.txt

export BOT_TOKEN="ضع_التوكن_الجديد_هنا"
export REMBG_MODEL="u2netp"
export U2NET_HOME="$PWD/.rembg"
.venv/bin/python -m services.background_remover --prepare
.venv/bin/python bot.py
```

يوجد مثال خدمة systemd في `deploy/telegram-services-bot.service`، لكن Docker Compose هو المسار الأسهل لتثبيت Tesseract وبقية الاعتماديات بنفس الإصدارات في كل خادوم.

## تنسيق ملف جهات الاتصال

تقبل خدمة تحويل جهات الاتصال إلى VCF ملفًا واحدًا أو عدة ملفات حتى `MAX_MULTI_FILES`، بأي مزيج من الصيغ `.xlsx` و`.xls` و`.csv` و`.txt` و`.vcf` و`.docx` و`.pdf`. حجم كل ملف حتى الحد المضبوط في `MAX_EXCEL_CONTACTS_FILE_MB`. يرسل المستخدم الملفات واحدًا تلو الآخر ثم يضغط «انتهيت».

- **Excel:** تُختار ورقة العمل التي يحتوي صف عناوينها على `الاسم الكامل` و`رقم التواصل`، و`البريد الالكتروني` اختياري.
- **CSV وجداول Word وPDF:** يُقرأ الجدول حسب عناوين أعمدته، بالعربية أو الإنجليزية، مثل `الاسم` و`الكنية` و`الهاتف` و`Name` و`Phone`. تُدعم ملفات تصدير Google Contacts وOutlook، وملفات CSV المحفوظة من Excel العربي بترميز Windows-1256 وبفاصلة منقوطة.
- **النص الحر في TXT وWord وPDF:** يُقرأ سطرًا سطرًا. يؤخذ الرقم والبريد من السطر، والباقي هو الاسم. إذا جاء الاسم في سطر والرقم في السطر التالي يُجمعان في جهة واحدة.
- **VCF:** تُنظف جهات الاتصال المصدّرة من الهاتف وتُدمج مكرراتها، بما فيها نسخ Android القديمة المرمّزة بـ Quoted-Printable.
- لا تُدعم ملفات PDF الممسوحة ضوئيًا دون طبقة نص، ولا ملفات Word القديمة بصيغة `.doc`.
- الجهة التي تحمل أكثر من رقم تبقى جهة واحدة بكل أرقامها، حتى 10 أرقام.
- السجلات التي تشترك برقم واحد على الأقل جهة واحدة، ولو جاءت من ملفات مختلفة. يُحتفظ بأول ظهور، وتُضاف إليه الأرقام الجديدة والبريد إن لم يكن له بريد.
- لا تُدمج جهتان لمجرد تشابه الاسم، لأن شخصين قد يحملان الاسم نفسه.
- إذا كان لجهة رقم صالح وآخر غير صالح، تُحفظ بالرقم الصالح ويظهر الآخر في تقرير المراجعة.
- عند دمج عدة ملفات، يُذكر اسم الملف مع كل موقع في التقارير، مثل `google.csv - 3`.

بعد رفع الملفات يطلب البوت رمز الدولة الافتراضي للأرقام المحلية، مثل `963` لسوريا. يرسل البوت ملف `contacts.vcf` مباشرة للاستيراد، ثم يرسل حزمة ZIP تحتوي على:

- `contacts.vcf` للاستيراد في الهاتف.
- `google_contacts.csv` بصيغة الاستيراد في Google Contacts، مع عمود لكل رقم.
- `clean_contacts.xlsx` بالجهات المنظفة وعمود للأرقام الإضافية.
- `merged_duplicates.xlsx` و`invalid_rows.xlsx` و`summary.txt` للمراجعة.

## تحويل نسخ ColorNote

تقبل خدمة ColorNote ملف Backup واحدًا أو عدة ملفات حتى الحد المضبوط في `MAX_COLORNOTE_FILES`. بعد انتهاء رفع الملفات يطلب البوت كلمة المرور المشتركة بينها، مع زر لاستخدام كلمة المرور الافتراضية `0000`. تدمج الخدمة الملاحظات حسب UUID، وتحتفظ بأحدث نسخة، ثم تعيد ملف HTML مستقلًا يعمل دون إنترنت ويدعم البحث والفلاتر والوضع الليلي.

## إدارة وحماية PDF

- إدارة الصفحات تدعم تدوير صفحات محددة أو جميع الصفحات، وحذف نطاقات مع منع حذف الملف كاملًا، وإعادة الترتيب بشرط ذكر كل صفحة مرة واحدة.
- حماية PDF تستخدم `AES-256-R5`. فك الحماية لا يحاول كسر كلمة المرور؛ يجب على المستخدم إرسال كلمة المرور الصحيحة.
- لا تُحفظ كلمات المرور بعد انتهاء العملية، وتبقى حدود عدد الصفحات والحجم والمهلة مطبقة.

## تحويل Word وExcel وPowerPoint إلى PDF

تستخدم الخدمة LibreOffice (Writer وCalc وImpress) داخل الحاوية، ولذلك أصبحت صورة Docker أكبر من قبل. يأخذ تحويل الملف بين ثانية و15 ثانية تقريبًا.

- تُقبل ملفات `.docx` و`.xlsx` و`.pptx`. الصيغ القديمة `.doc` و`.xls` و`.ppt` والملفات المحمية بكلمة مرور تُرفض برسالة واضحة.
- لملفات Excel خياران: حسب إعدادات الطباعة في الملف، أو كل ورقة في صفحة واحدة. الخيار الثاني يمنع تقطيع الجداول العريضة، لكن الورقة الطويلة جدًا (مئات الصفوف) تصبح صفحة واحدة طويلة تناسب الشاشة لا الطباعة.
- كل شريحة في PowerPoint تصبح صفحة.
- يعمل كل تحويل في ملف تعريف LibreOffice مؤقت خاص به، فيمكن تشغيل أكثر من تحويل في الوقت نفسه، ويُوقف التحويل الذي يتجاوز المهلة.
- `services/office_to_pdf/fonts.conf` يربط خطوط Microsoft والخطوط التجارية بخطوط مجانية: Arial وCalibri إلى خطوط بالمقاسات اللاتينية نفسها مع Noto Sans Arabic UI للعربية، وTimes New Roman وSimplified Arabic إلى Noto Naskh Arabic UI. ويُثبَّت خط الهوية Hayyakum من `assets/syid/fonts`.
- قبل التحويل يُصحَّح المستند في نسخة مؤقتة (`services/office_to_pdf/docx_fixes.py`) ليقرأه LibreOffice كما يقرؤه Word: أحجام العناوين في مستندات Google Docs، والفهرس التلقائي، والشعارات العائمة في الفقرات العربية.
- اختُبرت الخدمة على عشرة مستندات عربية حقيقية فيها جداول وصور وخطوط مختلفة. النتيجة قريبة من Word، لكنها ليست مطابقة: حروف Noto العربية أكبر قليلًا من حروف Arial، فقد يزيد عدد الصفحات صفحة أو أكثر، وقد تنزاح مربعات النص العائمة في بعض الأغلفة.

## ضغط PDF

- **بدون فقدان جودة:** يضغط محتوى الصفحات ويدمج الأجزاء المكررة، ولا يلمس الصور.
- **متوسط:** يصغّر الصور التي يتجاوز ضلعها الأطول 2000 بكسل ويعيد ضغطها بجودة JPEG 70.
- **قوي:** حد 1200 بكسل وجودة 45.
- لا تُعاد معالجة الصور الشفافة ولا صور المسح بالأبيض والأسود، ولا أي صورة لن يصغر حجمها بعُشر على الأقل.
- إذا لم يصغر الملف بنسبة 1% على الأقل، يُعاد الملف الأصلي كما هو مع رسالة توضح ذلك.
- ملفات PDF التي تخزّن صورها بترميز ASCII85 القديم بطيئة الفك، وقد تتجاوز مهلة المعالجة إذا كانت صورها كبيرة جدًا.

## أدوات Excel

- تدعم خدمات التنظيف والتقسيم والدمج ملفات `.xlsx` فقط.
- التنظيف يحذف الصفوف الفارغة والصفوف المكررة بعد صف العناوين ويزيل المسافات المحيطة بالنصوص.
- التقسيم يعمل على الورقة النشطة حسب اسم عمود أو حرفه، وبحد أقصى 50 قيمة مختلفة، ويعيد حزمة ZIP مع تقرير مختصر.
- دمج الصفوف يتطلب تطابق عناوين الأعمدة في الأوراق النشطة. ويمكن بدلًا منه جمع جميع أوراق الملفات داخل مصنف واحد.
- لحماية موارد الخادوم، يُرفض المصنف الذي يتجاوز مليون خلية أو 100 ورقة أو 200MB بعد فك ضغط حاوية XLSX.

## تدقيق النص العربي

- ترسل النص كرسالة واحدة حتى 5000 حرف، ويعيده البوت مصححًا ومنسقًا في فقرات.
- يصحح الإملاء والهمزات والتاء المربوطة وعلامات الترقيم العربية والمسافات والتطويل والرموز الدخيلة.
- يحوّل العامية إلى الفصحى بالكامل، ولا يترك النص خليطًا بين الاثنتين.
- لا يغيّر المعنى ولا يلخّص ولا يترجم، ويحتفظ بالأرقام والروابط والبريد الإلكتروني كما هي.
- يوجد تنظيف ميكانيكي في `tidy` يعمل قبل الطلب وبعده، فلا تكون النتيجة أسوأ من تنظيف حتمي حتى لو أخطأ النموذج.
- يُرفض الرد إذا أعاد النموذج نصًا أقصر من 60% من الأصل، منعًا من تسليم نص منقوص كأنه نص المستخدم.
- إذا تجاوزت النتيجة 3500 حرف تُرسل كملف `corrected_text.txt` بدل رسالة.

## إضافة خدمة جديدة

1. أضف الصنف إلى `SERVICE_CATEGORIES` عند الحاجة، ثم أضف تعريف الخدمة مع حقل `category` إلى `SERVICES` في `config.py`.
2. أضف المعالج إلى مجلد `services/`.
3. اربط الخدمة بحالة المحادثة المناسبة في `bot.py`.
4. أضف اختبارًا يغطي ملفًا صحيحًا ومدخلًا غير صالح.

## الأمان والخصوصية

- لا يوجد توكن داخل الكود، وملف `.env` مستبعد من Git وDocker build context.
- الحاوية تعمل بمستخدم غير root وبنظام ملفات للقراءة فقط، ولا يُسمح لها باكتساب صلاحيات جديدة.
- ملفات المستخدم تُنزّل إلى `/tmp` وتُحذف تلقائيًا بعد المعالجة.
- في العمليات متعددة الخطوات يحتفظ البوت بمعرفات Telegram فقط إلى أن يضغط المستخدم «انتهيت».
- توجد حدود لكل ملف، وإجمالي العملية، وعدد الملفات، وحجم النتيجة، والوقت، والتزامن.
- لا تُفك حماية ملفات PDF إلا بكلمة المرور الصحيحة، ولا توجد أي محاولة لكسرها.

> التوكن الذي كان موجودًا في النسخة القديمة مكشوف؛ يجب إلغاؤه من BotFather واستخدام توكن جديد.

## حل خطأ Numba داخل Docker

إذا ظهر الخطأ `cannot cache function ... no locator available` فهذا يعني أن Numba حاولت الكتابة داخل نظام الملفات المقروء فقط. النسخة الحالية توجه الكاش إلى `/tmp/numba` وتسمح للبوت بالبدء حتى لو تعذر تجهيز نموذج إزالة الخلفية.

بعد تحديث الملفات نفذ:

```bash
docker compose down
docker compose build --no-cache
docker compose up -d
docker compose ps
docker compose logs -f --tail=100
```

لا حاجة إلى حذف volume `rembg-models`.
